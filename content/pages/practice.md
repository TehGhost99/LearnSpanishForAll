# Practice
# Práctica

**EN:** Reading about Spanish is not the same as using Spanish. Each day: a short cue → a real speaking/writing task (~10–15 min) → written checks graded when you are signed in.

**ES:** Leer sobre español no es usarlo. Cada día: una pista corta → una tarea real (~10–15 min) → comprobaciones escritas con calificación si inicias sesión.

**EN:** The plan is flexible (~150 sessions). Missed days shift the end date, not the sequence. You can go **back a step** inside a session, take a **≤3-minute spaced test** (day / week / month prior), see **grades by day**, check a **practice calendar**, and ask the **Llama tutor** on the side for translations — without it giving away check answers.

**ES:** El plan es flexible (~150 sesiones). Los días perdidos mueven el final, no la secuencia. Puedes **volver un paso**, hacer una **prueba espaciada ≤3 min**, ver **notas por día**, un **calendario**, y usar el **tutor Llama** sin que te revele las respuestas.
