How to study this lesson / Cómo estudiar

  1. EN: Skim once for meaning. ES: Lee una vez para entender.
  2. EN: Cover English and retrieve Spanish. ES: Cubre el inglés y recupera el español.
  3. EN: Say example lines aloud. ES: Di ejemplos en voz alta.
  4. EN: Open Practice for today's session. ES: Abre Practice para la sesión de hoy.

Method notes / Notas de método

EN: We combine comprehensible input (understand first), spaced retrieval (recall later), and ACTFL-style can-do goals (what you can do with the language).

ES: Combinamos input comprensible, recuperación espaciada y metas tipo ACTFL (lo que puedes hacer con el idioma).

Key takeaway / Idea clave

Small daily speaking + retrieval beats long passive study. / Un poco de hablar y recuperar cada día vence el estudio pasivo largo.
